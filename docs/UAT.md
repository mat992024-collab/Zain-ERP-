# دليل القبول الفني (UAT) — Zain ERP

الغرض: التحقق العملي من جاهزية النظام على جهاز العميل قبل التسليم، بما يشمل الأجهزة
(طابعة حرارية 80/58 مم، قارئ باركود) والعمل دون اتصال.

## قبل البدء

| البند | الأمر / الخطوة |
|---|---|
| تثبيت الاعتماديات | `npm install` |
| فحص البيئة والبيانات | `npm run doctor` (يجب أن تكون النتيجة 0 خطأ) |
| بيانات تجريبية للعرض | `npm run seed` |
| تشغيل التطبيق | `npm start` |
| تصفير القاعدة للاختبار النهائي | `npm run reset` |
| الاختبارات الآلية | `npm test` (321 API + 14 رسم + 139 متصفح) |

بيانات الدخول الافتراضية: `admin` / `admin` — يجب تغيير كلمة المرور قبل التشغيل الفعلي.

## ملاحظات الأجهزة

- الطابعة الحرارية: ثبّت درايفر ESC/POS، اختر `thermal80` أو `thermal58` في الإعدادات،
  واترك هوامش المتصفح على «افتراضي». اختبر 9.1 و9.2 قبل التسليم.
- قارئ الباركود: اضبطه على «Keyboard Wedge» مع CR كإرسال، ثم اختبر 2.2.
- إذا ظهرت مشكلة بيئية، شغّل `npm run doctor` وأرسل المخرجات مع لقطات الشاشة.
