# Zain ERP

نظام زين المحاسبي والشامل (Multi-Industry ERP + AI Engine) خفيف جداً يعمل بقاعدة بيانات SQLite على سطح المكتب.

## الميزات
- عربي بالكامل مع اتجاه RTL
- واجهات حديثة بتقنية Tailwind CSS
- وضع فاتح ووضع داكن (يُبدَّل من زر الهيدر أو من الإعدادات)
- نقاط البيع (بيع سريع + مفصل)
- سرعة نقاط البيع: اختصارات لوحة المفاتيح، أصناف سريعة، تكرار آخر فاتورة، تعليق/استئناف السلة، شريط تنبيه النواقص
- المخزون والأصناف + تنبيهات النواقص
- العملاء، الموردون، الخزنة، المصروفات، الأقساط
- الذكاء الاصطناعي: تحليل مبيعات، التنبؤ بالنواقص، اقتراحات ذكية
- طباعة حرارية 80/58 مم، فواتير A4، ملصقات باركود
- دعم قارئ الباركود
- أدوار وصلاحيات
- تصدير CSV (Excel متوافق) لفواتير البيع والشراء والأصناف والعملاء والموردين والمصروفات والحسابات والورديات والخزنة وسجل النشاط
- نسخ احتياطي واستعادة قاعدة البيانات مع صور الأصناف (أرشيف zip واحد يضم القاعدة والصور) وintegrity check قبل الاستعادة، مع نسخ تلقائي إلى مجلد خارجي (قرص/فلاش)
- حد ائتمان العملاء (أنماط: تحذير / منع / بدون) مع تجاوز المدير ومراجعة الرصيد
- مرتجع الشراء (يُنقص المخزون ومستحقات المورد) ومرتجع البيع (سليم يعيد للمخزون / تالف لا يعيده) مع رد المبلغ بنفس طريقة الدفع الأصلية
- كشف حساب للعميل/المورد مع أعمار الذمم (0-30 / 31-60 / 61-90 / 90+) وطباعته
- قائمة الدخل (إيرادات، تكلفة بضاعة، مجمل ربح، مصروفات، صافي ربح) وهوامش ربح الأصناف
- سندات القبض والصرف والنقل بين الحسابات (مع طباعة وإلغاء مع عكس الأثر)
- تقرير Z (مبيعات وطرق دفع وحركة نقدية وتوزيع ساعي) + تقرير انتهاء صلاحية الأصناف
- تعدد العملات: جدول أسعار الصرف، اختيار عملة الدفع في نقاط البيع، وتقرير أرصدة العملات
- دفع مختلط (نقدي + بطاقة + محفظة) مع خانة لكل طريقة، حساب المتبقي والآجل تلقائياً، وتخزين تفصيل الدفع في الفاتورة وتقارير الخزنة والوردية وZ
- أسعار متعددة العملات لكل صنف (بيع/تكلفة/جملة) تُدار من بطاقة الصنف وتُستخدم تلقائياً عند الدفع بعملة أجنبية في نقاط البيع
- نسخ احتياطي تلقائي يومي بوقت قابل للضبط مع تنظيف النسخ القديمة
- قوالب طباعة قابلة للتخصيص (ترويسة، تذييل، شعار، حجم خط، كثافة) للفاتورة الحرارية وA4 والملصقات
- تذكيرات: نص تذكير يومي (صلاحيات، نواقص، ذمم، مبيعات) جاهز للنسخ، تذكيرات مخصصة متكررة، ولوحة تنبيهات
- تقرير المخزون (قيمة التكلفة والبيع حسب التصنيف) + طباعة دفتر أستاذ الحساب وحركة الصنف
- ضريبة مُحسوبة تلقائياً من نسبة ضريبة كل صنف (أو أسعار شاملة الضريبة) مع حساب ضريبة مستحق وتقرير ضريبي وطباعته
- سجل نشاط (Audit Log) بواجهة عرض مع تصفية بالإجراء والمستخدم والتاريخ وتصدير CSV
- تحليل المبيعات: الأصناف الأكثر مبيعاً، المبيعات حسب العميل، المبيعات اليومية مع طباعة التقرير
- بحث سريع عام (Ctrl+K) في الأصناف والعملاء والموردين والفواتير مع الانتقال المباشر للواجهة
- صور الأصناف: رفع صورة مع تصغير تلقائي، حفظها على القرص في `data/images/`، عرض مصغّرة في قائمة الأصناف وبطاقات نقاط البيع والأصناف السريعة، وظهورها في فاتورة A4 وملصقات الباركود
- تكرار فاتورة بيع/شراء أو سند قبض/صرف/نقل بنقرة واحدة (مع فحص حد الائتمان وتجاوزه عند الحاجة)
- فواتير مجدولة: جدولة فواتير بيع/شراء متكررة (يومي/أسبوعي/شهري/سنوي) تُنشأ تلقائياً عند وقت الاستحقاق، مع إيقاف/تنشيط وتشغيل فوري من شاشة الجدولة
- أقساط: تتبع تلقائي للأقساط المتأخرة (مهمة يومية) مع إظهارها في تقرير التذكير اليومي
- عدّ لأقل استهلاك للموارد (Node.js + node:sqlite)

## التشغيل
1. تثبيت الحزم: `npm install`
2. بناء CSS: `npm run build:css`
3. تشغيل: `npm start` (يفتح متصفح Edge في وضع تطبيق)
4. أو للخادم فقط: `npm run serve`
5. فحص الجاهزية قبل التسليم: `npm run doctor` (بيئة، قاعدة بيانات، نسخ احتياطي، مساحة، منفذ)

## الاختبارات
```
npm test              # يشغّل الثلاث مجموعات بالترتيب
npm run test:api      # اختبارات الـ API (352 فحصاً)
npm run test:render   # رسم كل الشاشات في بيئة DOM وهمية (14 فحصاً)
npm run test:ui       # متصفح Chrome/Edge حقيقي عبر CDP (153 فحصاً)
```
- `test:api` يستخدم قاعدة بيانات منفصلة `data/test/e2e.db`
- `test:render` و `test:ui` يستخدمان `data/test/render-test.db` و `data/test/ui-test.db`
- مجلد الاختبارات `data/test/` معزول تماماً عن بيانات التشغيل الحقيقية (`data/zain.db` و`data/images/`)
- `test:ui` يتحقق أيضاً من عدم وجود أي طلب شبكة خارجي (عمل كامل بدون إنترنت)
- `test:ui` يغطي تدفق بيع كامل في المتصفح + طباعة الإيصال الحراري والفاتورة A4 وملصقات الباركود (مع توليد PDF فعلي)
- `test:ui` يتحقق من تبديل المظهر (فاتح/داكن) ومن حفظه في الإعدادات
- `test:ui` ينزّل ملف CSV فعلياً من المتصفح ويتحقق من الـ BOM
- `test:ui` ينشئ نسخة احتياطية من داخل واجهة الإدارة
- `test:ui` يغطي تحذير حد الائتمان (تجاوز من مدير) وتبويب قائمة الدخل وكشف الحساب وعمود الربح في فواتير البيع
- `test:ui` يغطي اختصارات نقاط البيع (تعليق السلة F3، استئنافها F4، تكرار آخر فاتورة F5) والأصناف السريعة وشريط النواقص
- `test:ui` يغطي تبويب السندات (حفظ سند جديد من الواجهة) وتبويب تقرير Z ونافذة تقرير انتهاء الصلاحية
- `test:ui` يغطي شاشة سجل النشاط (العرض، تصفية الإجراء، ودقة العداد)
- `test:ui` يغطي رفع صورة صنف (المعاينة في النموذج، الإزالة، ظهورها في قائمة الأصناف وبطاقات نقاط البيع)
- `test:ui` يغطي النسخ الاحتياطي (أرشيف zip يضم القاعدة والصور) وتنزيله من واجهة الإدارة
- `test:ui` يغطي تكرار الفاتورة والسند من القوائم (نافذة التأكيد + فاتورة/سند جديد)

## اختصارات نقاط البيع
| المفتاح | الوظيفة |
|---|---|
| `F1` / `F2` | التركيز على البحث/الباركود |
| `F3` | تعليق السلة الحالية |
| `F4` | فتح السلال المعلّقة |
| `F5` | تكرار آخر فاتورة |
| `F9` | إتمام البيع |
| `Esc` | مسح حقل البحث |

## المجلدات
- `src/server/` الخادم + قاعدة البيانات + API
- `src/web/` الواجهة الأمامية
- `src/web/assets/vendor/` الخطوط والأيقونات المحلية (Bootstrap Icons + Cairo)
- `tests/` الاختبارات الآلية
- `data/` قاعدة البيانات `zain.db` (والنسخ الاحتياطية في `data/backups/<اسم القاعدة>/` كأرشيفات zip، وصور الأصناف في `data/images/`)
- `src/launcher.js` مشغل التطبيق الخفيف

## ملاحظات
- يعمل بدون إنترنت بعد التنصيب (لا توجد أي موارد خارجية وقت التشغيل)
- يفترض وجود Microsoft Edge أو Google Chrome
- أول تشغيل ينشئ المستخدم الادمن تلقائياً
- عند تعديل `src/web/styles.css` يجب إعادة البناء: `npm run build:css`
